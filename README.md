# Tirthesh Bari — MSTS & Open Rails personal brand website

A responsive, static personal-brand website with profile SEO, social links, JSON-LD ProfilePage/Person structured data, sitemap, robots.txt, and a GitHub profile README draft.

## Before publishing
1. Choose and register a domain you control.
2. Replace every `YOUR-DOMAIN.com` in `index.html`, `robots.txt`, and `sitemap.xml` with the real domain (without adding a trailing slash to the domain itself).
3. Replace `hello@YOUR-DOMAIN.com` in `index.html` with an email address you control, or remove the contact button.
4. Confirm the bio and project descriptions are accurate. Add only real project links, contributions, awards or appointments.
5. If you have a formal appointment from a project/community organization, update the ambassador wording only with accurate evidence. Otherwise retain “Independent Community Ambassador”.

## Preview locally
Open `index.html` in a browser. For a local web server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Deploy on GitHub Pages
1. Create a public website repository named `tirtheshbari18.github.io` under your GitHub account (this is the standard GitHub Pages user-site repository name).
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)`.
4. If using a custom domain, configure it in Pages and follow GitHub's DNS instructions. Do not publish until DNS and HTTPS are configured.
5. Verify the live URL and update the canonical URL, Open Graph URL, sitemap and README website link to match the exact final domain.

## Add the GitHub profile README
1. Create a separate public repository named exactly `tirtheshbari18` (the repository name must match your GitHub username).
2. Copy `GITHUB_PROFILE_README.md` into that repository as `README.md` and commit it.
3. Replace the website placeholder with your real published website URL.

## Search visibility checklist
- Verify the domain in [Google Search Console](https://search.google.com/search-console) and [Bing Webmaster Tools](https://www.bing.com/webmasters/).
- Submit `/sitemap.xml` in both webmaster tools.
- Inspect the homepage URL and request indexing after deployment.
- Test structured data with [Schema Markup Validator](https://validator.schema.org/) and Google's [Rich Results Test](https://search.google.com/test/rich-results/). ProfilePage markup is descriptive; it does not guarantee a special rich result.
- Publish original project pages and useful tutorials with visible text, dates, screenshots you own or have permission to use, and links to the actual repositories.
- Keep your name, short bio and profile links consistent on GitHub, Instagram, YouTube and relevant community profiles.
- Earn genuine references from community projects, forums and collaborators. Do not buy links, create fake accounts, or post repetitive keyword spam.
